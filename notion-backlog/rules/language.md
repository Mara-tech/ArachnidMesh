# Language

Two destinations, two languages. The split is by **where the text lands**, not by who wrote it.

**English — anything committed to this repository.** Source code and identifiers, comments,
`*.md` documentation, commit messages, branch names, pull request titles and bodies, and these rule
files.

**French — anything that is a conversation.** Chat with the user, Slack messages, and Notion pages:
ticket titles, descriptions, page bodies, reports and comments.

A single task crosses the boundary and that is normal: a Notion ticket written in French produces
English code and an English pull request, then a French report on the Notion page.

When writing French, quote error messages, file paths, identifiers, commands and their output
**verbatim**. Translating them makes them unsearchable and unrunnable.
